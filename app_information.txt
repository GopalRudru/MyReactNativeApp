          Application Information

INTRODUCTION
------------
The Avanse Customer Mobile App is a comprehensive React Native-based mobile application designed to provide Avanse 
customers with secure and convenient access to their financial services. This mobile platform serves as a digital 
gateway for customers to manage their loans, track disbursements, process payments, and access various banking services 
directly from their smartphones.

Built with modern technology stack including React Native and TypeScript, the app ensures cross-platform compatibility for 
both Android and iOS devices while maintaining high performance and security standards.

APP DETAILS
-----------
Name: Avanse Financial Services
Platform: React Native (Cross-platform - Android & iOS)
Technology Stack: React Native, TypeScript, Redux Toolkit
Security Framework: FreeRASP (Runtime Application Self-Protection)

KEY FEATURES
------------
• Secure Authentication System
• Comprehensive Loan Management Dashboard with Real-time Updates
• Disbursement Tracking and Status Monitoring
• Secure Payment Processing via Avanse Web Gateway
• Document Upload & Download with Document Management
• Push Notifications for Critical Updates and Alerts
• Advanced Runtime Security with FreeRASP Protection
• SSL Pinning and Certificate Validation
• Anti-tampering and Root/Jailbreak Detection
• Encrypted Local Data Storage
• User Profile Management
• Payment Transaction History
• Quick Help and Customer Support Integration

TECHNICAL SPECIFICATIONS
------------------------
Frontend Framework: React Native 0.76.9
Programming Language: TypeScript 5.0.4
State Management: Redux Toolkit
Navigation: React Navigation v7
Build Tools: Metro bundler
Security: FreeRASP Integration
Analytics: Firebase Analytics
Push Notifications: Firebase Cloud Messaging
Storage: AsyncStorage
Network: Fetch API for HTTP communications

SUPPORTED PLATFORMS
-------------------
• Android (API Level 24+)
• iOS (iOS 15.0+)

SECURITY FEATURES
-----------------
• Runtime Application Self-Protection (RASP)
• SSL Pinning for Secure Communications
• Data Encryption at Rest and in Transit
• Secure Token-based Authentication
• Anti-tampering and Anti-debugging Protection
• Root/Jailbreak Detection

PAYMENT GATEWAY INTEGRATION
---------------------------
The mobile app integrates with payment gateways through Avanse's web-based 
payment infrastructure, providing secure and seamless payment processing:

• Primary Integration: Avanse Web Payment Portal
  - URL: https://payment.avanse.com/
  - Secure WebView integration within mobile app
  - Supports multiple payment methods (UPI, Cards, Net Banking)

• Payment Gateway Features:
  - Real-time transaction processing
  - Multi-bank support
  - Secure payment tokenization
  - Transaction status tracking
  - Payment history and receipts

• Security Measures:
  - SSL/TLS encryption for all payment communications
  - PCI DSS compliant payment processing
  - Two-factor authentication for high-value transactions
  - Fraud detection and prevention mechanisms

DEVELOPMENT SETUP INSTRUCTIONS
------------------------------
Complete setup guide for fresh macOS machine to develop the Avanse Financial Services mobile app.

PREREQUISITES
-------------
• macOS 15.0 (Sequoia) or later
• Admin privileges on the machine
• Stable internet connection
• Apple ID (for Xcode and iOS development)

1. REACT NATIVE ENVIRONMENT SETUP
----------------------------------

Step 1: Install Homebrew
-------------------------
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Step 2: Install Node.js and npm
--------------------------------
# Install Node.js (LTS version)
brew install node

# Verify installation
node --version  # Should show v18.x.x or later
npm --version   # Should show v9.x.x or later

Step 3: Install Watchman
-------------------------
# Install Facebook's Watchman for file watching
brew install watchman

Step 4: Install React Native CLI
---------------------------------
# Install React Native CLI globally
npm install -g react-native-cli

# Install React Native CLI (new architecture)
npm install -g @react-native-community/cli

Step 5: Install CocoaPods (for iOS)
------------------------------------
# Install CocoaPods for iOS dependency management
sudo gem install cocoapods

# Verify installation
pod --version

2. ANDROID STUDIO SETUP
------------------------

Step 1: Download and Install Android Studio
--------------------------------------------
1. Visit: https://developer.android.com/studio
2. Download Android Studio for macOS
3. Install the .dmg file
4. Launch Android Studio and complete setup wizard

Step 2: Install Android SDK
----------------------------
1. Open Android Studio
2. Go to Preferences > Appearance & Behavior > System Settings > Android SDK
3. Install the following SDK platforms:
   • Android 14 (API Level 34)
   • Android 13 (API Level 33)
   • Android 12 (API Level 31)
   • Android 11 (API Level 30)
   • Android 10 (API Level 29)

Step 3: Install Android SDK Build-Tools
----------------------------------------
In SDK Manager, go to SDK Tools tab and install:
• Android SDK Build-Tools (latest version)
• Android SDK Command-line Tools
• Android SDK Platform-Tools
• Android Emulator
• Intel x86 Emulator Accelerator (HAXM installer)

Step 4: Configure Environment Variables
---------------------------------------
Add to your ~/.zshrc or ~/.bash_profile:
# Android SDK
export ANDROID_HOME=$HOME/Library/Android/sdk
export PATH=$PATH:$ANDROID_HOME/emulator
export PATH=$PATH:$ANDROID_HOME/platform-tools
export PATH=$PATH:$ANDROID_HOME/cmdline-tools/latest/bin

# Java (if needed)
export JAVA_HOME=/Applications/Android\ Studio.app/Contents/jre/Contents/Home

Step 5: Create Android Virtual Device (AVD)
--------------------------------------------
1. Open Android Studio
2. Go to Tools > AVD Manager
3. Click "Create Virtual Device"
4. Select device (e.g., Pixel 4)
5. Download and select system image (API 30 or higher)
6. Configure AVD settings and finish

Step 6: Verify Android Setup
-----------------------------
# Reload shell configuration
source ~/.zshrc

# Check Android SDK
adb version

# List available emulators
emulator -list-avds

1. Open Mac App Store

3. Test simulator functionality

TROUBLESHOOTING
---------------

Common Issues and Solutions:
• Metro bundler cache issues: `npm start -- --reset-cache`
• iOS build issues: `cd ios && pod install && cd ..`
• Android build issues: `cd android && ./gradlew clean && cd ..`
• Permission issues: Check Android SDK permissions
• Simulator not starting: Restart Android Studio/Xcode

Useful Commands:
# Clear all caches
npm start -- --reset-cache
cd ios && pod deintegrate && pod install && cd ..
cd android && ./gradlew clean && cd ..

# Check React Native environment
npx react-native doctor

# View connected devices
adb devices              # Android devices
xcrun simctl list       # iOS simulators

RELEASE BUILD CREATION
----------------------

1. ANDROID RELEASE BUILD FOR GOOGLE PLAY STORE
-----------------------------------------------

Build Using Android Studio
----------------------------------------------
1. Open Android Studio
2. Open the project (select android folder)
3. Wait for Gradle sync to complete
4. Go to Build menu > Generate Signed Bundle / APK
5. Select "Android App Bundle" (recommended) or "APK"
6. Click "Next"
7. Key store path: Browse and select "app/avanseRelease.keystore"
8. Enter Key store password
9. Key alias: Select your key alias from dropdown
10. Enter Key password
11. Click "Next"
12. Select build variant: "release"
13. Signature versions: Check both V1 and V2
14. Click "Finish"
15. Wait for build to complete
16. Click "locate" to find generated files

Android Studio Build Output Locations:
• AAB: android/app/release/app-release.aab
• APK: android/app/release/app-release.apk


Build Using Command
----------------------------------------------
Step 1: Verify Signing Key
--------------------------
# Signing key is already available at:
# android/app/avanseRelease.keystore

# Verify keystore exists
ls -la android/app/avanseRelease.keystore

Step 2: Build Release APK/AAB
------------------------------
# Clean previous builds
cd android && ./gradlew clean && cd ..

# Build release APK
cd android && ./gradlew assembleRelease && cd ..

# Build release AAB (recommended for Play Store)
cd android && ./gradlew bundleRelease && cd ..

# Generated files location:
# APK: android/app/build/outputs/apk/release/app-release.apk
# AAB: android/app/build/outputs/bundle/release/app-release.aab

Step 3: Verify Release Build
----------------------------
# Install release APK on device for testing
adb install android/app/build/outputs/apk/release/app-release.apk

# Check APK alignment
zipalign -v -c 4 android/app/build/outputs/apk/release/app-release.apk


Step 4: Upload to Google Play Console
--------------------------------------
1. Login to Google Play Console
2. Navigate to your app
3. Go to Production > Create new release
4. Upload the AAB file (app-release.aab)
5. Fill in release notes and version information
6. Review and publish

2. IOS RELEASE BUILD FOR APP STORE
----------------------------------

Step 1: Configure Xcode Project
-------------------------------
1. Open `ios/avanseCustomerApp.xcworkspace` in Xcode
2. Select the project root in navigator
3. Go to Signing & Capabilities tab
4. Set Team to your Apple Developer account
5. Ensure Bundle Identifier matches App Store Connect

Step 2: Configure Release Settings
----------------------------------
1. Select "avanseCustomerApp" scheme
2. Edit Scheme > Run > Build Configuration: Release
3. Product > Scheme > Edit Scheme
4. Set Build Configuration to "Release" for Archive

Step 3: Archive the App
-----------------------
1. Select "Any iOS Device" or connected device
2. Product > Archive
3. Wait for archive process to complete
4. Xcode Organizer will open automatically

Step 4: Distribute to App Store
-------------------------------
1. In Xcode Organizer, select the archive
2. Click "Distribute App"
3. Select "App Store Connect"
4. Choose distribution options:
   - Upload your app's symbols: Yes
   - Manage Version and Build Number: Yes
5. Review and upload

Step 5: Submit for Review in App Store Connect
----------------------------------------------
1. Login to App Store Connect
2. Navigate to your app
3. Go to TestFlight tab to verify upload
4. Move to App Store tab
5. Create new version if needed
6. Fill in:
   - App Information
   - Pricing and Availability
   - App Privacy
   - App Review Information
7. Submit for review
